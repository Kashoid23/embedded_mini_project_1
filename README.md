## Обладнання

- **ESP32-S3 N16R8**
- фоторезистор (LDR) і резистор для дільника напруги
- модуль реле
- навантаження на контактах реле (світлодіод)

## Схема

<img width="879" height="392" alt="Схема підключення" src="https://github.com/user-attachments/assets/b3033e49-5f7f-4a3c-8300-c50a9d915e4f" />



| Компонент | ESP32-S3 |
|---|---|
| Дільник: 3V3 → фоторезистор → **GPIO4** → резистор → GND | GPIO4 (АЦП) |
| Реле IN | GPIO6 |
| Реле VCC / GND | живлення модуля, GND спільна з платою |

Фоторезистор стоїть у верхньому плечі дільника. У темряві його опір росте, напруга на GPIO4 падає, і значення АЦП зменшується.

## Як це працює

```
GPIO4 (АЦП, 0…4095) ──► порівняння з порогами ──► GPIO6 ──► реле
```

1. **Зчитування.** `analogRead()` дає значення 0…4095 (роздільна здатність 12 біт).
2. **Порівняння з порогами (гістерезис):**

   | Значення АЦП | Що відбувається |
   |---|---|
   | < 1600 (`kThresholdDark`) | темно → реле **ON** |
   | 1600…2200 | стан не змінюється |
   | > 2200 (`kThresholdLight`) | світло → реле **OFF** |

3. **Керування реле.** Новий стан записується на GPIO6.
4. **Лог.** Значення і стан реле виводяться в монітор порту кожні 200 мс.

### Навіщо гістерезис

З одним порогом шум АЦП і плавна зміна освітлення біля межі змушували б реле постійно перемикатися. Зона 1600…2200 між порогами гасить ці коливання: реле перемикається лише тоді, коли освітленість змінилась суттєво.

## Вивід у монітор порту

```
RAW = 2840 | Relay = OFF
RAW = 1950 | Relay = OFF
RAW = 1420 | Relay = ON
RAW = 1880 | Relay = ON
RAW = 2350 | Relay = OFF
```

## Налаштування

| Файл | Параметр | Значення |
|---|---|---|
| `include/config.h` | `kLdrPin` | 4 |
| | `kRelayPin` | 6 |
| | `kResolution` | 12 біт |
| | `kBaud` | 115200 |
| `include/sensor.h` | `kThresholdDark` | 1600 |
| | `kThresholdLight` | 2200 |

Пороги залежать від фоторезистора, резистора дільника і освітлення в кімнаті. Щоб підібрати свої, подивіться значення `RAW` у моніторі при світлі і в темряві.

## Структура проєкту

```
include/config.h   піни і параметри АЦП
include/sensor.h   пороги і API датчика
include/relay.h    API реле
src/sensor.cpp     налаштування і читання АЦП
src/relay.cpp      керування піном реле
src/main.cpp       гістерезис і лог
```

## Збірка

1. Відкрити проєкт у VS Code з PlatformIO.
2. **Build**, потім **Upload**, потім **Monitor** (115200).
